## Posting Order

1. Instagram carousel: general introduction to CivicBrands and the KC directory.
2. Facebook opener: "Useful public information, built for the people who actually use it."
3. Facebook KC directory: push the practical value of the metro resource list.
4. Facebook corrections: ask the community to flag wrong hours, broken numbers, and missing resources.
5. Facebook privacy: reinforce trust with "No ads. No trackers. No selling data."

## Caption Drafts

### Instagram Carousel

CivicBrands is here to make useful public information easier to find, check, reuse, and correct.

The KC directory covers both sides of the metro: food, housing, healthcare, legal aid, crisis lines, transit, utilities, local government, and more. It is built for real use, which means confidence labels, correction paths, and public data exports.

If a number stops working or something is missing, tell us: civicbrands.org/kc/suggest

### Facebook Opener

Useful public information, built for the people who actually use it.

CivicBrands builds practical civic infrastructure: directories, public records, resource pages, and systems that make responsibility easier to trace.

civicbrands.org

### Facebook KC Directory

Kansas City, both states.

The CivicBrands KC directory covers food, housing, healthcare, legal aid, crisis lines, transit, utilities, local government, and more across the bi-state metro.

Start here: civicbrands.org/kc

### Facebook Corrections

If a number stops working, tell us.

Wrong hours, missing services, disconnected phones, and "they turned me away" reports all matter. Corrections help the next person show up with better information.

Send updates: civicbrands.org/kc/suggest

### Facebook Privacy

No ads. No trackers. No selling data.

Public information should not come with a hidden invoice.

civicbrands.org
