open-cognition is a reference substrate for governed agent memory.

It defines immutable canonical objects, agent-scoped references, and a universal stop lifecycle so distributed AI systems remain auditable, attributable, and resistant to silent state manipulation.

The project focuses on:
- governed memory structures
- provenance preservation
- attributable state transitions
- operational auditability
- distributed agent coordination
- and reversible memory interaction patterns
