This artifact represents the record-sufficiency pattern used to examine whether a system preserves enough information for affected stakeholders to understand, contest, and review consequential actions.

The matrix pattern is relevant when evaluating:

- public records
- agency decisions
- procurement materials
- procedural documentation
- AI-mediated summaries
- institutional impact claims

The publication version should preserve the analytical structure while removing private, privileged, or operationally sensitive material.
